Use them

Replay them in the integration's tests

From a checkout of the integration:

python scripts/fetch_samples.py --meter
pytest -m replay

Filters: --unit, --power-supply, --meter, --defrost, --all. Files go to tests/samples/.

Compare two branches

CSNET_REPLAY_REPORT=head.json pytest -m replay
git switch main
CSNET_REPLAY_REPORT=base.json pytest -m replay
python -m tests.replay.report base.json head.json

Prints each day's electricity, heat and COP before → after, next to the meter and CSNet's own heat.

The file format

A gzip JSON Lines file. The first line is a header; every other line is one reply of CSNet Manager, redacted like the diagnostics download, or a meter reading:

{"t": 61.2, "kind": "installation_devices", "data": {…}}
{"t": 61.2, "kind": "meter", "energy_kwh": 1234.5, "power_w": 1830}

Share your unit

1. Record

In Home Assistant, run the action CSNet Home: Start sample recording (2 days or more). Pick your meter's power sensor if you have one. The file lands in csnet_home_samples/ of your configuration folder.

2. Check

Names, position, account and serial numbers are removed, but the replies keep your zone names, dates and times. Read what a sample contains before sharing it.

3. Send it

Open a Share a sample issue and attach the file, or open a pull request adding it under samples/<your-unit>/. Samples are shared under CC0.
